# EXCEPTIONS ทะเบียนข้อยกเว้นที่ยอมรับแบบมีเงื่อนไข
> ห้ามยอมรับค่าที่ตกเกณฑ์แบบเงียบๆ · ทุกข้อต้องมีเลข E-xxx และเกณฑ์ที่**แคบที่สุด**
> System Sheet ต้องแสดงจำนวน exception ที่ยัง open เสมอ ห้ามประกาศ "WCAG AA" ลอยๆ ขณะมีข้อค้าง

## Format
### E-{nnn}: {สั้นๆ} OPEN | CLOSED
- **ที่ไหน:** component/token + path
- **ค่าที่วัดได้ / เกณฑ์:** เช่น 2.99:1 vs 3:1
- **เหตุผลที่ยอมรับ:** ต้องอธิบายว่าทำไมกรณีนี้ไม่กระทบผู้ใช้จริง
- **ขอบเขต (สำคัญที่สุด):** เงื่อนไขแคบที่สุดที่ทำให้ยอมรับได้ ห้ามอ้างข้อนี้กับเคสที่ไม่เข้าเงื่อนไขทุกข้อ
- **ทางออกถ้าจะปิด:** ต้องทำอะไรถึงจะไม่ต้องมี exception นี้
- **วันที่ / ผู้อนุมัติ:**

### E-001: ตัวอักษรขาวบนกระจกบาง (brightness 0.42) เหนือรูปที่มีจุดแดดจัด OPEN
- **ที่ไหน:** ทุก text บน `Card` (glass) token `brightness.bright` = 0.42 (`packages/tokens/src/primitive.json`); วัดโดย `tooling/glass-evidence.mjs` (`E001_FLOOR`) ทั้ง harness และหนังสือ 26 หน้า × 4 ฉาก × 3 โหมด
- **ค่าที่วัดได้ / เกณฑ์:** 131 จาก 144,564 text check (รอบ 2026-10-27, 2 ธีม × 4 ฉาก × 3 โหมด; ทั้ง 131 อยู่ในธีม dark, ธีม light ผ่าน 4.5:1 ครบ) อยู่ที่ 3.8–4.49:1 ที่ pixel แย่สุดใต้กล่องตัวอักษร vs เกณฑ์ 4.5:1 (normal text); ไม่มี node ไหนต่ำกว่า 3.8:1
- **เหตุผลที่ยอมรับ:** user สั่งให้กระจกบางลง ("ทึบไป ต้องบางกว่านี้"); 0.38 ผ่านครบทุก node แต่เป็นกระจกทึบที่ user ปฏิเสธ; ค่าที่ตกเป็น worst pixel ของกล่องตัวอักษร (รวมช่องว่างเหนือ/ใต้ตัวอักษร) ไม่ใช่ค่าเฉลี่ย และมี halo รอบตัวอักษรแล้ว
- **ขอบเขต (สำคัญที่สุด):** เฉพาะตัวอักษรบน glass Card เหนือรูปพื้นหลังที่ระบบไม่ได้คุม และเฉพาะที่ ≥3.8:1 ห้ามอ้างกับปุ่มพื้นทึบ (light/accent), แท็บที่เลือก, focus ring, หรือ node ใดที่ต่ำกว่า 3.8:1 (นับเป็น fail ตามเดิม)
- **ทางออกถ้าจะปิด:** (1) brightness 0.38 (ผ่านครบ แต่ทึบขึ้น) หรือ (2) Environment ที่ sample รูปพื้นหลังจริงตามตำแหน่งการ์ด แล้วหรี่เฉพาะการ์ดที่ทับจุดสว่าง (BACKLOG)
- **วันที่ / ผู้อนุมัติ:** 2026-10-26 / agent ตามคำสั่ง user ให้กระจกบางลง รอ user ยืนยัน

### E-002: Input `sm` สูง 32px ต่ำกว่า press area 44px ของ P6 OPEN
- **ที่ไหน:** `Input` size `sm` (`packages/react/src/components/Input/Input.module.css` `.sm`, token `input.height-sm` = 32px) มี `data-touch-exempt` บน element เมื่อ size เป็น `sm`
- **ค่าที่วัดได้ / เกณฑ์:** 32px vs 44px ของ P6 (G-TT1); ผ่าน WCAG 2.2 2.5.8 Target Size (Minimum) ที่ 24px
- **เหตุผลที่ยอมรับ:** `<input>` วาด pseudo-element ไม่ได้ จึงขยาย press area แบบ Button, Select, Chip และ Tabs ไม่ได้ ถ้าจะให้ตัว element สูง 44px แต่เห็นร่องสูง 32px ต้องใช้ border ใสรอบช่อง ซึ่งทำให้ช่องไม่ตรงแนวกับ control อื่นและวง focus ไม่ตรงร่อง ขนาด sm มีไว้สำหรับแถบเครื่องมือบน desktop ที่ใช้เมาส์
- **ขอบเขต (สำคัญที่สุด):** เฉพาะ Input `sm` เท่านั้น ห้ามอ้างกับ Input `md`, Textarea, PinInput หรือ control อื่น ทุกตัวนั้นต้องได้ 44px; บนจอสัมผัสให้ใช้ `md` (หนังสือเขียนไว้ในหน้า Input)
- **ทางออกถ้าจะปิด:** ให้ FormField หรือ InputGroup ห่อ Input sm ด้วย label `[data-hit]` สูง 44px ที่ส่งการคลิกเข้า input หรือเลิกใช้ `sm`
- **วันที่ / ผู้อนุมัติ:** 2026-10-28 / agent รอ user ยืนยันตอน milestone review

### E-003: Citation มี press area 24px ต่ำกว่า 44px ของ P6 OPEN
- **ที่ไหน:** `Citation` (`packages/react/src/components/Citation/Citation.module.css` `.mark::after`, token `citation.hit` = 24px) มี `data-touch-exempt` บนปุ่ม
- **ค่าที่วัดได้ / เกณฑ์:** 24px vs 44px ของ P6 (G-TT1); ผ่าน WCAG 2.2 2.5.8 Target Size (Minimum) ข้อยกเว้น inline ที่ 24px
- **เหตุผลที่ยอมรับ:** citation อยู่ในบรรทัดข้อความเหมือนเชิงอรรถ ถ้าให้กดได้ 44px จะดันบรรทัดให้สูงขึ้นหรือทับคำข้างเคียงจนกดผิด WCAG ยกเว้นเป้าหมายแบบ inline ไว้ตรงนี้โดยตรง
- **ขอบเขต (สำคัญที่สุด):** เฉพาะ Citation ในบรรทัดข้อความเท่านั้น รายการแหล่งที่มาแบบแยกบรรทัดต้องใช้ List หรือ Link ที่ได้ 44px
- **ทางออกถ้าจะปิด:** มีรายการแหล่งที่มาใต้คำตอบ (44px ต่อแถว) ให้กดแทนได้ทุกครั้ง แล้วยกเลิกข้อยกเว้น
- **วันที่ / ผู้อนุมัติ:** 2026-10-31 / agent รอ user ยืนยันตอน milestone review

### E-004: card ยังห่างจาก anchor A เรื่องความสว่างของตัวกระจก (G-AN1) OPEN
- **ที่ไหน:** Card บน `/components/card/code` ฉาก forest ธีม dark เทียบกับการ์ด A ใน `apps/lab/concept-check/index.html` (บันทึกไว้ที่ `system/anchor/anchor-likeness.json`)
- **ค่าที่วัดได้ / เกณฑ์:** body lightness (OKLab) 0.29 เทียบกับ anchor 0.53 ห่างกัน 0.24 ซึ่งเกินเกณฑ์ 0.05 ส่วน chroma และ rim อยู่ในเกณฑ์
- **เหตุผล:** D-035 หรี่ฉากหลังลงเพื่อให้ตัวหนังสือได้ 4.5:1 บนรูปถ่าย ส่วน A ใช้ตัวกระจกสีเทาโดยไม่หรี่เลย กระจกจึงดูสว่างกว่า นี่คือจุดเดียวกับที่ R-032 บอกไว้ว่ากระจกค่อยๆ หลุดจาก anchor
- **ขอบเขต:** เฉพาะ G-AN1 ซึ่งตั้งเป็น advisory ไว้ ส่วน contrast ของตัวหนังสือยังเป็น gate บังคับเหมือนเดิม
- **ทางออกถ้าจะปิด:** ให้ user เลือกระหว่าง (ก) ยอมรับ D-035 เป็น anchor ใหม่ แล้วรัน `anchor-likeness.mjs --record` ใหม่ หรือ (ข) ขยับตัวกระจกกลับไปทาง A (body สว่างขึ้นและหรี่น้อยลง) แล้วยอมรับ E-001 ในฉากที่สว่าง
- **วันที่ / ผู้อนุมัติ:** 2026-10-31 / agent รอ user ตัดสินตอน milestone review
