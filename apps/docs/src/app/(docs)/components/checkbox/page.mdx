# Checkbox

Checkbox renders a native `<input type="checkbox">`, visually hidden underneath a custom box drawn
with real SVG check/indeterminate glyphs. It's the one selection control in this wave explicitly
called out as not needing React Aria/Radix — a bare native checkbox already gets correct
keyboard/focus behavior for free. Use it for boolean choices and "select all" style indeterminate
groups.

```tsx
import { Checkbox } from 'dial-react';
```

## Composition

A common real-world pattern: a "select all" parent checkbox above a list of child checkboxes. The
parent renders `indeterminate` whenever some but not all children are checked, and toggles every
child when clicked itself — the parent/child relationship is owned entirely by the caller, exactly
as the `indeterminate` prop doc describes.

## Accessibility

**Keyboard:** Tab to focus, Space to toggle — both are native `<input type="checkbox">` behavior,
verified directly in `Checkbox.test.tsx` (tab into the control, then `Space` fires `onChange`).

**Screen reader:** The native input carries the real `checked`/`indeterminate`/`disabled` state
and receives focus, so screen readers announce it exactly as a normal checkbox. When
`indeterminate`, `aria-checked="mixed"` is also set explicitly. The custom visual box is
`aria-hidden` and purely decorative on top of the real input.

**Focus:** Focus-visible renders as an outline ring (`--ds-focus-ring-*` tokens) around the custom
box, not a shadow. The wrapper (`label`) has `min-inline-size`/`min-block-size: size.control.sm`
(40px) for a web-first hit area, while the visible box stays visually smaller (`size.icon.lg`) and
centered within it via flex.

## Related

- `Radio` and `Switch` — the other two native-input-based selection controls, sharing the same
  visually-hidden-input + custom-visual technique and 40px hit-area pattern.
- `Fieldset` — groups multiple checkboxes/radios under a shared `<legend>`.
- `FormField` — can wrap a single Checkbox to attach a `Label`/`HelperText`, though checkboxes are
  more commonly labeled inline via their own wrapping `label`.
