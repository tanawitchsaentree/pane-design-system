# Kbd

Renders a native `<kbd>` element to visually represent a keyboard key or shortcut (e.g. `Esc`,
`Ctrl`, `K`).

```tsx
import { Kbd } from 'dial-react';
```

## Demo

<Demo code={`<Kbd>Esc</Kbd>`}>
  <BasicKbd />
</Demo>

## Usage

Kbd renders a native `<kbd>` element to visually represent a keyboard key or shortcut (e.g. `Esc`,
`Ctrl`, `K`). It uses the system's mono font stack and a hairline border instead of a decorative
shadow. It has a single size and no variants — a key cap is a fixed-identity UI element in this
system, not something that needs a t-shirt scale.

## Variants

Kbd has a single size and no variants by design — a key cap is a fixed-identity UI element in
this system.

<Demo code={`<Kbd>Ctrl</Kbd> + <Kbd>K</Kbd>`}>
  <ChordedKbd />
</Demo>

Shortcuts with three or more keys chain the same pattern: one `Kbd` per key, separated by a plain
`+` character, in the order the keys are physically pressed.

<Demo code={`<Kbd>Cmd</Kbd> + <Kbd>Shift</Kbd> + <Kbd>K</Kbd>`}>

</Demo>

## Keyboard interaction

N/A — Kbd is non-interactive and never receives focus.

## Accessibility

**Keyboard:** N/A — Kbd is non-interactive and never receives focus.

**Screen reader:** Renders a real native `<kbd>` element with its text content as-is; no
additional ARIA is applied or needed since `<kbd>` already carries correct native semantics.

**Focus:** Not focusable; no focus-visible styling is defined.
