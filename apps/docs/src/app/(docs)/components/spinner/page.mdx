# Spinner

An indeterminate loading indicator — a pure CSS animation with no client state, so it's safe to
render on the server.

```tsx
import { Spinner } from 'dial-react';
```

## Usage

Spinner is an indeterminate loading indicator — a pure CSS animation with no client state, so it's
safe to render on the server. Use it to communicate an in-progress/busy state, either standalone or
composed inside Button (rendered automatically when `loading` is true).

## Variants

Spinner's only variant-like prop is `size` (matching the icon size scale); `label` changes the
accessible name announced, not the visual.

<Demo code={`<Spinner size="sm" />
<Spinner size="md" />
<Spinner size="lg" />
<Spinner size="xl" label="Saving changes" />`}>
  <SpinnerSizesLabel />
</Demo>

## Composition

The most common real use is inside a `Button`: setting `loading` swaps Button's icon slot for a
Spinner automatically and marks the button `aria-busy`/`disabled` — no manual composition needed.

<Demo code={`<Button loading intent="primary">Save changes</Button>`}>
  <SpinnerInButton />
</Demo>

Standalone, Spinner is used inside a content region (e.g. a panel waiting on results) rather than
on a control — the `label` here describes what's loading, not a generic "Loading".

<Demo code={`<Flex align="center" justify="center" style={{ width: 240, height: 120 }}>
  <Spinner size="lg" label="Loading results" />
</Flex>`}>

</Demo>

## Accessibility

**Keyboard:** N/A — Spinner is non-interactive and never receives focus.

**Screen reader:** Root `span` has `role="status"` (implying `aria-live="polite"`), containing a
visually-hidden label as real text content (not just an attribute) so the accessible name —
`"Loading"` by default, or the custom `label` — is announced once.

**Focus:** Not focusable; no focus-visible styling is defined. Respects `prefers-reduced-motion`
by swapping the spin animation for an opacity pulse (D-009 motion tokens).
