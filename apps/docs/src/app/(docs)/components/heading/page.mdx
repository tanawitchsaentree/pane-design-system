# Heading

Renders a real `h1`-`h6` element for document-outline structure, with visual size deliberately
decoupled from semantic level.

```tsx
import { Heading } from 'dial-react';
```

## Demo

<Demo code={`<Heading level={2}>Section title</Heading>`}>
  <BasicHeading />
</Demo>

## Usage

Heading renders a real `h1`-`h6` element for document-outline structure, with visual size
deliberately decoupled from semantic level — so a small-looking `h1` or a large-looking `h4` are
both legitimate combinations. Use it anywhere content needs a heading in the accessibility tree;
pick `level` for correct document structure and `size` (or let it default) for visual weight.

## Composition

A realistic content block: an `h1` article title paired with `Text` byline copy, then an `h2`
subheading followed by a body paragraph — the kind of structure Heading is actually meant to sit
inside, rather than an isolated single line.

## Accessibility

**Keyboard:** N/A — Heading is non-interactive and never receives focus.

**Screen reader:** Always renders a real heading tag (`h1`-`h6`) matching `level`, so screen
readers announce correct heading level/document outline regardless of the visual `size` chosen —
unless `asChild` overrides the tag entirely.

**Focus:** Not focusable; no focus-visible styling is defined.
