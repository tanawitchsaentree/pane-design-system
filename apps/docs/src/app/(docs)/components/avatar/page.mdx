# Avatar

Displays a user/entity image with an automatic fallback to initials (or short text) when no `src`
is given, or when the image fails to load.

```tsx
import { Avatar } from 'dial-react';
```

## Demo

<Demo code={`<Avatar src="https://i.pravatar.cc/80?img=12" alt="Jordan Lee" fallback="JL" />`}>
  <BasicAvatar />
</Demo>

## Usage

Avatar displays a user/entity image with an automatic fallback to initials (or short text) when no
`src` is given, or when the image fails to load. It's a client component (`"use client"`) because
it tracks image-load-error state internally to perform that swap. Use it for user profile
pictures, team member lists, or any identity representation that needs a graceful fallback.

## Accessibility

**Keyboard:** N/A — Avatar is non-interactive and never receives focus.

**Screen reader:** When an image renders successfully, it exposes the required `alt` as its
accessible name. When falling back (no `src`, or the image errored), the fallback `span` gets
`role="img"` + `aria-label` (using `alt` or `fallback` text, defaulting to `'Avatar'`) so a screen
reader gets a real name instead of reading raw initials as if they were a word.

**Focus:** Not focusable; no focus-visible styling is defined.
