# HelperText

HelperText is the supporting copy shown under a form control — hint text, validation errors,
character limits. It renders through `Text` for typography consistency and exposes a `tone` prop
to switch between neutral guidance and error messaging. It is purely presentational; the actual
`aria-describedby` wiring to its control is the caller's job, or automatic when composed through
`FormField`.

```tsx
import { HelperText } from 'dial-react';
```

## Composition

When `HelperText` is used outside `FormField`, the caller wires `aria-describedby` on the control
by hand, pointing at `HelperText`'s own `id`. This shows that manual pairing with a real `Label` +
`Input`.

<Demo code={`<Stack gap="100">
  <Label htmlFor="email-field">Email</Label>
  <Input id="email-field" type="email" aria-describedby="email-helper" placeholder="you@example.com" />
  <HelperText id="email-helper">We'll never share your email with anyone else.</HelperText>
</Stack>`}>
  <HelperTextWithManualInput />
</Demo>

The more common case composes `HelperText` inside `FormField`, which wires `id`/`aria-describedby`
automatically and switches `HelperText` to `tone="error"` on its own whenever `invalid` is set —
no separate `tone` prop needed on `HelperText` itself.

<Demo code={`<FormField label="Password" invalid helperText="Password must be at least 8 characters.">
  <Input type="password" defaultValue="abc" />
</FormField>`}>
  <HelperTextInFormField />
</Demo>

## Accessibility

**Keyboard:** None — HelperText is static text, not an interactive element.

**Screen reader:** Purely presentational on its own; announced to assistive tech only when a
control references it via `aria-describedby` (wired automatically by `FormField`, or manually by
the caller otherwise). The `data-tone` attribute is a styling hook, not an ARIA signal — tone
changes rely on the caller/`FormField` also switching to `aria-invalid` where relevant.

**Focus:** Not focusable.

## Related

- `FormField` composes `HelperText` under the control and wires `aria-describedby` (and switches
  `tone` to `'error'` when `invalid`) automatically.
- `Label` — the other text-bearing atom composed by `FormField`, following the same "render
  through `Text`" pattern.
- `Input` / `Textarea` — typical controls whose validation state HelperText communicates.
