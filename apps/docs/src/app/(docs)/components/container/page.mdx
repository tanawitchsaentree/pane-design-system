# Container

Container centers content horizontally and caps its width at a breakpoint size, extending Box.

```tsx
import { Container } from 'dial-react';
```

## Demo

<Demo code={`<Container size="lg">

</Container>`}>
  <BasicContainer />
</Demo>

## Usage

Container centers content horizontally and caps its width at a breakpoint size, extending Box
(D-012). Use it as the outermost wrapper for page sections or content areas that should stay
readable-width on large viewports rather than stretching edge-to-edge.

## Variants

<Demo code={`<Container size="sm">

</Container>`}>

`size="full"` removes the max-width cap entirely, letting content span the full available width —
the right choice for a full-bleed hero or a section that should stretch edge-to-edge instead of
being capped.

## Composition

A typical use wraps a real page section — a heading, some body copy, and an action — rather than
a single line of placeholder text. This shows `Container` at its default `size="lg"` around that
kind of content.

    <Text color="subtle">
      Manage your team's members, roles, and billing details from one place.
    </Text>
    <Button intent="primary">Invite member</Button>
  </Stack>
</Container>`}>

## Accessibility

**Keyboard:** N/A — non-interactive layout primitive.

**Screen reader:** No inherent role; `size` is exposed only via a `data-size` attribute for
styling. Verified axe-clean in tests.

**Focus:** Not focusable itself; forwards ref to the underlying DOM node.
