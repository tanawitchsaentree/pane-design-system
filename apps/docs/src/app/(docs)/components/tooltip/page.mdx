# Tooltip

Tooltip is a small, text-only hint bubble attached to a trigger element, typically shown on hover
or keyboard focus.

```tsx
import { Tooltip } from 'dial-react';
```

## Usage

Tooltip is a small, text-only hint bubble attached to a trigger element, typically shown on hover
or keyboard focus. Per D-002 ("web-first"), hover is treated as a first-class trigger here rather
than adapted away for touch — Tooltip is an explicit carve-out from the system's usual mobile-first
defaults. It is deliberately shadow-free (no `shadow.elevation`), since it's meant to read as "a
thin text hint," not a floating panel with elevation weight. Every `Tooltip.Root` must live inside
a `Tooltip.Provider`, which shares hover-intent timing across sibling tooltips.

## Variants

`side` (on `Tooltip.Content`, default `'top'`) is the only variant-shaped prop — it picks which
edge of the trigger the hint bubble renders against.

<Demo code={`<Tooltip.Provider>
  <Tooltip.Root>
    <Tooltip.Trigger asChild>
      <IconButton aria-label="Add item"><PlusSvg /></IconButton>
    </Tooltip.Trigger>
    <Tooltip.Content side="right">Add item</Tooltip.Content>
  </Tooltip.Root>
</Tooltip.Provider>`}>
  <SideTooltip />
</Demo>

`Tooltip.Root`'s `delayDuration` overrides the provider's shared hover-intent delay per instance —
here a destructive icon-only action opens its hint immediately (`delayDuration={0}`) instead of
waiting out the default 700ms.

<Demo code={`<Tooltip.Provider>
  <Tooltip.Root delayDuration={0}>
    <Tooltip.Trigger asChild>
      <IconButton aria-label="Delete item"><TrashSvg /></IconButton>
    </Tooltip.Trigger>
    <Tooltip.Content>Delete item</Tooltip.Content>
  </Tooltip.Root>
</Tooltip.Provider>`}>
  <InstantTooltip />
</Demo>

## Accessibility

**Keyboard:** Tooltip opens on keyboard focus of the trigger (not hover-only, confirmed in
`Tooltip.test.tsx`: "opens on keyboard focus"), and closes on Escape or when the trigger blurs.

**Screen reader:** Radix renders the content with `role="tooltip"`, associated to the trigger via
`aria-describedby` — dismissal on Escape/trigger-blur is automatic, not hand-rolled. Verified
axe-clean when open.

**Focus:** Tooltip does not trap or move focus — it simply appears near the currently-focused/
hovered trigger and disappears on blur or Escape.
