# Input

Input is a native `<input>`-based single-line text field. Per the system's behavior rule, a plain
text input needs no React Aria/Radix wrapper — the browser already provides correct semantics and
keyboard behavior. Use it for any short free-text or typed value (email, name, price) and pair it
with `leftElement`/`rightElement` for small inline adornments like a currency symbol or unit.

```tsx
import { Input } from 'dial-react';
```

## Keyboard interaction

No keyboard behavior beyond native `<input>` Tab-to-focus and standard text-editing keys — nothing
custom.

## Accessibility

**Keyboard:** Native `<input>` keyboard behavior (Tab to focus, standard text-editing keys) — no
custom key handling.

**Screen reader:** `invalid` sets `aria-invalid="true"` on the actual `<input>`; `disabled` uses
the native attribute (removes from tab order) rather than `aria-disabled`; `readOnly` uses the
native attribute too (stays focusable/selectable). Label association and `aria-describedby` to
helper text are the caller's responsibility unless composed via `FormField`.

**Focus:** Focus lands on the native `<input>` itself, not the wrapper `span`; adornments are
`aria-hidden` and never receive focus.

## Related

- `FormField` composes Input with `Label` and `HelperText`, wiring `id`/`aria-describedby`/
  `aria-invalid`/`required` automatically.
- `InputGroup` — use instead of `leftElement`/`rightElement` for a multi-character prefix/suffix
  segment (e.g. "$" + amount + "USD").
- `Textarea` — the multi-line counterpart, same size/invalid token pattern.
