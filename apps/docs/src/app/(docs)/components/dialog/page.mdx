# Dialog

Dialog is the system's blocking modal overlay — use it for tasks that must interrupt the user's
flow and require a decision or input before they can return to the page underneath.

```tsx
import { Dialog } from 'dial-react';
```

## Usage

Dialog is the system's blocking modal overlay — use it for tasks that must interrupt the user's
flow and require a decision or input before they can return to the page underneath (confirmations,
forms, critical alerts). It renders through a portal at `z-index: var(--ds-z-index-modal)` (1400)
with `shadow.elevation.lg`, the heaviest elevation permitted in the system, and inerts the
background while open. If the interruption doesn't need to be blocking, prefer Popover (non-modal
auxiliary panel) or Drawer (edge-anchored panel) instead.

## Variants

`size` on `Dialog.Content` (`'sm' | 'md' | 'lg' | 'full'`, default `'md'`) is the t-shirt width
preset; `'full'` fills the viewport. `hideCloseButton` hides the built-in close button for dialogs
that supply their own explicit action buttons instead.

<Demo code={`<Dialog.Root>
  <Dialog.Trigger asChild>
    <Button intent="danger" variant="outline">Delete account</Button>
  </Dialog.Trigger>
  <Dialog.Content size="sm" hideCloseButton>
    <Dialog.Title>Delete account?</Dialog.Title>
    <Dialog.Description>This action cannot be undone.</Dialog.Description>
    <Dialog.Close asChild>
      <Button variant="ghost">Cancel</Button>
    </Dialog.Close>
    <Dialog.Close asChild>
      <Button intent="danger">Delete</Button>
    </Dialog.Close>
  </Dialog.Content>
</Dialog.Root>`}>

## Accessibility

**Keyboard:** Tab/Shift+Tab cycles focus only within the open dialog (focus trap via Radix);
Escape closes it and returns focus to the trigger.

**Screen reader:** Renders `role="dialog"` (Radix), announced by its `Dialog.Title` as the
accessible name, with `Dialog.Description` (if present) linked via `aria-describedby`. Verified
axe-clean when open in `Dialog.test.tsx`.

**Focus:** Radix moves focus into the content on open (confirmed in tests:
`toContainElement(document.activeElement)`); focus returns to the trigger element on close.
Background content is made inert while the modal is open.

## Related

- **Drawer** — same `@radix-ui/react-dialog` state machine and Content shape, differing only in
  CSS entrance/exit animation (edge slide-in vs. center scale).
- **Popover** — lighter, non-modal alternative for auxiliary panels that shouldn't block the page.
- **Toast/Snackbar** — for transient notifications instead of a blocking decision point.
