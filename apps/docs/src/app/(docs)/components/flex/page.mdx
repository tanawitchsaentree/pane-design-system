# Flex

Flex is the flexbox layout primitive extending Box, for arranging children in a row or column
with control over gap, alignment, justification, and wrapping.

```tsx
import { Flex } from 'dial-react';
```

## Usage

Flex is the flexbox layout primitive extending Box (D-012). Use it whenever you need to arrange
children in a row or column with control over gap, alignment, justification, and wrapping. It's
the general-purpose flexbox building block that more specific primitives (Stack, Center) wrap for
common cases.

## Variants

`direction` (`'row'` default, or `'column'`) is Flex's most basic axis switch.

<Demo code={`<Flex direction="column" gap="200">
  <div>One</div>
  <div>Two</div>
  <div>Three</div>
</Flex>`}>
  <FlexColumn />
</Demo>

<Demo code={`<Flex align="center" style={{ width: '100%' }}>
  <div>Label</div>
  <Spacer />
  <div>Action</div>
</Flex>`}>
  <FlexWithSpacer />
</Demo>

`gap` accepts any `SpaceToken` step, unset by default (no gap unless explicitly given).

<Demo code={`<Flex gap="100">
  <div>One</div>
  <div>Two</div>
  <div>Three</div>
</Flex>
<Flex gap="700">
  <div>One</div>
  <div>Two</div>
  <div>Three</div>
</Flex>`}>
  <FlexGap />
</Demo>

`align` sets cross-axis alignment across children of different sizes — `'stretch'` makes every
child fill the cross axis instead of sizing to its own content.

<Demo code={`<Flex align="start">
  <div style={{ height: 40 }}>A</div>
  <div style={{ height: 80 }}>B</div>
  <div style={{ height: 60 }}>C</div>
</Flex>
<Flex align="stretch">
  <div>A</div>
  <div>B</div>
  <div>C</div>
</Flex>
<Flex align="end">
  <div style={{ height: 40 }}>A</div>
  <div style={{ height: 80 }}>B</div>
  <div style={{ height: 60 }}>C</div>
</Flex>`}>
  <FlexAlign />
</Demo>

`justify` distributes children along the main axis — `'around'` and `'evenly'` differ in how much
space surrounds the outermost children versus between siblings.

<Demo code={`<Flex justify="start" style={{ width: '100%' }}>
  <div>Start</div>
  <div>Middle</div>
  <div>End</div>
</Flex>
<Flex justify="around" style={{ width: '100%' }}>
  <div>Start</div>
  <div>Middle</div>
  <div>End</div>
</Flex>
<Flex justify="evenly" style={{ width: '100%' }}>
  <div>Start</div>
  <div>Middle</div>
  <div>End</div>
</Flex>`}>
  <FlexJustify />
</Demo>

`wrap` (default `'nowrap'`) lets children flow onto additional lines — `'wrap-reverse'` stacks
overflow lines in reverse order instead of below the first line.

<Demo code={`<Flex wrap="nowrap" gap="200" style={{ width: 220, overflow: 'auto' }}>
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>

</Flex>
<Flex wrap="wrap-reverse" gap="200" style={{ width: 220 }}>
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
  <div>Item 4</div>
</Flex>`}>

## Keyboard interaction

No keyboard behavior beyond native Tab focus — Flex is a non-interactive layout primitive.

## Accessibility

**Keyboard:** N/A — non-interactive layout primitive.

**Screen reader:** No inherent role; direction/align/justify/gap are exposed only as `data-*`
attributes for styling hooks, not conveyed to assistive tech. Verified axe-clean in tests.

**Focus:** Not focusable itself; forwards ref to the underlying DOM node. `asChild` (inherited from
Box) changes the rendered element but not the focus model beyond what that element natively
provides.
