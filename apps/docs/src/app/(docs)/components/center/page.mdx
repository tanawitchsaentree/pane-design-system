# Center

Center centers its children on both axes by wrapping Flex with `align="center"` and
`justify="center"` fixed internally.

```tsx
import { Center } from 'dial-react';
```

## Demo

<Demo code={`<Center style={{ height: 160 }}>
  <div>Centered content</div>
</Center>`}>
  <BasicCenter />
</Demo>

## Usage

Center centers its children on both axes by wrapping Flex with `align="center"` and
`justify="center"` fixed internally (D-012). Use it for the common "center this single
block/element" case — modals' inner content, empty states, spinners — without having to remember
Flex's align/justify prop names.

## Variants

`direction` (`'row'` default, or `'column'`) is inherited from Flex and controls whether multiple
children stack side by side or one above the other, still centered as a group on both axes.

<Demo code={`<Center direction="column" gap="200" style={{ height: 160 }}>
  <div>Row one</div>
  <div>Row two</div>
</Center>`}>
  <CenterColumn />
</Demo>

`gap` (inherited from Flex) sets the space between multiple centered children — larger gaps read
as more clearly separate items rather than one centered group.

<Demo code={`<Center direction="row" gap="900" style={{ height: 100 }}>
  <div>Left</div>
  <div>Right</div>
</Center>`}>
  <CenterGap />
</Demo>

`wrap` (inherited from Flex) lets children flow onto additional centered lines instead of
overflowing a fixed-width container.

<Demo code={`<Center wrap="wrap" gap="200" style={{ width: 220 }}>
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
  <div>Item 4</div>
</Center>`}>
  <CenterWrap />
</Demo>

## Composition

A common real-world use: centering a `Spinner` inside a loading placeholder area, filling the
space a dashboard section will occupy once its data has loaded.

<Demo code={`<Center style={{ height: 160 }}>
  <Spinner size="lg" label="Loading dashboard" />
</Center>`}>
  <CenterLoadingState />
</Demo>

Another common use: an empty state, centering a short message (and optional supporting copy)
inside an otherwise-empty content area — e.g. a table or list with no matching rows.

<Demo code={`<Center direction="column" gap="200" style={{ height: 160 }}>
  <Text weight="semibold">No results found</Text>
  <Text size="sm" color="subtle">
    Try adjusting your filters.
  </Text>
</Center>`}>
  <CenterEmptyState />
</Demo>

## Keyboard interaction

No keyboard behavior beyond native Tab focus — Center is a non-interactive layout primitive.

## Accessibility

**Keyboard:** N/A — non-interactive layout primitive.

**Screen reader:** No inherent role; renders as a Flex/Box `div` with `data-align="center"`/
`data-justify="center"` for styling only. Verified axe-clean in tests.

**Focus:** Not focusable itself; forwards ref to the underlying DOM node.
