# IconButton

A Button variant with only an icon and no visible text label, extending Button's
variant/intent/size/loading/asChild API 1:1.

```tsx
import { IconButton } from 'dial-react';
```

## Usage

IconButton is a Button variant with only an icon and no visible text label, extending Button's
variant/intent/size/loading/asChild API 1:1. It renders a true square hit target (width equals
height, matching `size.control.*`) instead of Button's rectangular padding, for toolbar actions,
close buttons, and other icon-only controls.

IconButton inherits Button's `size` scale (`sm`/`md`/`lg`/`xl`, `md`=48) — the square footprint
grows with it, so the hit target stays equal on both axes at every step.

`aria-busy="true"`, same as Button.

## Accessibility

**Keyboard:** Same as Button — native `<button>` semantics, `Tab` to focus, `Enter`/`Space` to
activate; disabled (including while `loading`) is removed from the tab order.

**Screen reader:** `aria-label` is a required prop (not optional) — it becomes the button's sole
accessible name since there is no visible text label for assistive tech to read.

**Focus:** Inherits Button's `:focus-visible` treatment — dedicated focus-ring token, never a
shadow ring.
