# Spacer

Spacer is a purely presentational spacing utility extending Box — it never carries content.

```tsx
import { Spacer } from 'dial-react';
```

## Usage

Spacer is a purely presentational spacing utility extending Box (D-012) — it never carries
content. With no `size` set it grows to fill available space (`flex: 1`) inside a flex container,
useful for pushing siblings apart; with a `size` set (a `SpaceToken`) it acts as a fixed-size gap.

## Composition

Inside a `Card.Header`, an unsized Spacer pushes a trailing metadata string away from the title
so the two ends of the row stay pinned regardless of the header's width.

<Demo code={`<Card.Root style={{ maxWidth: 320 }}>
  <Card.Header>
    <Flex align="center" style={{ width: '100%' }}>
      <Text weight="medium">Project Alpha</Text>
      <Spacer />
      <Text size="sm" color="subtle">Updated 2d ago</Text>
    </Flex>
  </Card.Header>
  <Card.Body>Shared workspace for the Alpha launch.</Card.Body>
</Card.Root>`}>
  <SpacerCardHeaderActions />
</Demo>

A sized Spacer also works as a one-off gap between grouped `Stack` children — larger than the
Stack's own uniform `gap`, to visually separate a "danger zone" section from the settings above it
without introducing a second Stack.

<Demo code={`<Stack gap="200" style={{ maxWidth: 320 }}>
  <div>General settings</div>
  <div>Notifications</div>
  <Spacer size="800" />
  <div>Danger zone</div>
</Stack>`}>
  <SpacerStackSectionBreak />
</Demo>

## Keyboard interaction

No keyboard behavior beyond native Tab focus — Spacer is a non-interactive layout primitive.

## Accessibility

**Keyboard:** N/A — non-interactive layout primitive.

**Screen reader:** Explicitly hidden via `aria-hidden="true"` — screen readers skip it entirely,
the same way they'd skip empty whitespace.

**Focus:** Not focusable; carries no content and no interactive semantics.
