# Badge

A small, non-interactive label for status/category/count indicators (e.g. "New", "Beta", a count
chip).

```tsx
import { Badge } from 'dial-react';
```

## Demo

<Demo code={`<Badge>New</Badge>`}>
  <BasicBadge />
</Demo>

## Usage

Badge is a small, non-interactive label for status/category/count indicators (e.g. "New", "Beta",
a count chip). It supports three fill treatments (`solid`/`subtle`/`outline`) and the full set of
semantic color roles (D-006). It is never focusable and has no hover/active state — it's content,
not a control.

## Accessibility

**Keyboard:** N/A — Badge is not focusable (no `tabindex`) and exposes no interactive role.

**Screen reader:** No implicit ARIA role beyond its plain text content; `role="status"` is
intentionally omitted by default per BLUEPRINT §7 ("don't guess a11y role beyond what's certain")
— consumers needing live-updating semantics should wrap the value in their own live region.

**Focus:** Not focusable; no focus-visible styling is defined.
