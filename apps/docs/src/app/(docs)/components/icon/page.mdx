# Icon

Sizes and colors an arbitrary SVG child via CSS custom properties — it ships no icon set of its
own, only the sizing/coloring wrapper.

```tsx
import { Icon } from 'dial-react';
```

## Usage

Icon sizes and colors an arbitrary SVG child via CSS custom properties — it ships no icon set of
its own, only the sizing/coloring wrapper (D-004 icon size scale). Use it any time you render an
SVG in the UI so it picks up the system's icon size steps and semantic color tokens consistently,
and gets the correct accessibility treatment for decorative vs. meaningful icons.

## Variants

`size` (16/20/24/32) and `color` (`currentColor`/`default`/`subtle`/`disabled`/`inverse`) are
Icon's only variant-like props; `label` toggles between decorative (`aria-hidden`) and meaningful
(`role="img"` + `aria-label`) treatment.

<Demo code={`<Icon size="sm"><StarSvg /></Icon>

<Icon size="xl" label="Favorite"><StarSvg /></Icon>`}>

## Paired with text

The common composition case: an icon next to a visible text label, `color='currentColor'` (the
default) so it inherits the label's color, and `label` omitted since the text already conveys the
meaning.

## Accessibility

**Keyboard:** N/A — Icon itself is non-interactive and never receives focus.

**Screen reader:** When `label` is provided, the wrapper gets `role="img"` + `aria-label` (icon is
meaningful on its own). When `label` is omitted (default), the wrapper gets `aria-hidden="true"`
(icon is decorative, relies on adjacent text for meaning).

**Focus:** Not focusable; no focus-visible styling is defined.
