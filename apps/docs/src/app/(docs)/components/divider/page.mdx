# Divider

Divider is a hairline rule extending Box, used to separate sections of content visually and
structurally.

```tsx
import { Divider } from 'dial-react';
```

## Demo

## Usage

Divider is a hairline rule extending Box (D-012), styled per D-008 (hairline border tokens define
the divider — no decorative shadow). Use it to separate sections of content visually and
structurally, either horizontally between stacked blocks or vertically between inline items.

## Composition

A realistic use of `Divider` is separating rows in a list of like items, rather than two generic
blocks — here it marks the boundary between line items in an invoice list.

<Demo code={`<Stack gap="0">
  <Flex justify="between" align="center">
    <Text>Invoice #1042</Text>
    <Text color="subtle">$240.00</Text>
  </Flex>
  <Divider />
  <Flex justify="between" align="center">
    <Text>Invoice #1041</Text>
    <Text color="subtle">$180.00</Text>
  </Flex>
  <Divider />
  <Flex justify="between" align="center">
    <Text>Invoice #1040</Text>
    <Text color="subtle">$95.00</Text>
  </Flex>
</Stack>`}>

</Demo>

A vertical `Divider` inside a toolbar separates related but distinct actions — here between an
"add" and a "delete" `IconButton` — instead of just adding horizontal spacing between them.

## Keyboard interaction

No keyboard behavior beyond native Tab focus — Divider is non-interactive; it exposes
`role="separator"` semantics rather than any interactive/keyboard-navigable role.

## Accessibility

**Keyboard:** N/A — non-interactive; exposes `role="separator"` semantics rather than any
interactive/keyboard-navigable role.

**Screen reader:** Announced as a structural separator via `role="separator"` and
`aria-orientation` (mirrors the `orientation` prop), so assistive tech treats it as a real divider
rather than decorative content.

**Focus:** Not focusable; purely structural.
