# Drawer

Drawer is an edge-anchored overlay panel that slides in from the left, right, or bottom of the
viewport.

```tsx
import { Drawer } from 'dial-react';
```

## Usage

Drawer is an edge-anchored overlay panel that slides in from the left, right, or bottom of the
viewport. It is built on the exact same `@radix-ui/react-dialog` state machine as Dialog (Reuse
Check, D-018) — the only functional difference is the CSS entrance/exit animation (slide-from-edge
instead of scale-from-center). Per D-017, the historical Sheet/BottomSheet role is folded into
Drawer as `placement="bottom"` rather than shipped as a separate component. Use it for secondary
panels (filters, item details, settings) that benefit from a spatial "slide in from an edge"
affordance instead of Dialog's centered blocking treatment.

## Variants

`placement` on `Drawer.Content` (`'left' | 'right' | 'bottom'`, default `'right'`) picks which
viewport edge the panel slides in from. `'bottom'` is full-width and height-capped (the former
Sheet/BottomSheet role, D-017); `'left'`/`'right'` are full-height and fixed-width.

## Accessibility

**Keyboard:** Tab/Shift+Tab cycles focus within the open drawer (focus trap via Radix, identical
to Dialog); Escape closes it.

**Screen reader:** Renders `role="dialog"` (Radix), with `Drawer.Title` supplying the accessible
name and `Drawer.Description` linked via `aria-describedby` when present. Verified axe-clean when
open in `Drawer.test.tsx`.

**Focus:** Focus moves into the content on open and returns to the trigger on close, same
mechanics as Dialog (inherited from `@radix-ui/react-dialog`).
