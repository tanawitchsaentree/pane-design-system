# Textarea

Textarea is a native `<textarea>`-based multi-line field, following the same no-wrapper rationale
as Input — a plain native element already gets correct semantics and keyboard behavior for free.
Use it for prose-length input (bio, comments, descriptions) where Input's single-line adornment
slots wouldn't make sense.

```tsx
import { Textarea } from 'dial-react';
```

## Composition

Textarea nested inside `FormField` needs no manual `id`/`aria-describedby` wiring — `FormField`
clones those onto the control automatically, linking the label and helper text for assistive tech.

<Demo code={`<FormField label="Bio" helperText="Shown on your public profile.">
  <Textarea placeholder="Tell us about yourself" rows={3} />
</FormField>`}>
  <TextareaInFormField />
</Demo>

A more realistic composition: a required comment field inside a real `<form>`, submitted with a
`Button` — the shape Textarea is actually used in, rather than an isolated field.

<Demo code={`<form onSubmit={(e) => e.preventDefault()}>
  <FormField label="Comment" required helperText="Be specific and constructive.">
    <Textarea placeholder="Leave a comment" rows={4} resize="vertical" />

## Accessibility

**Keyboard:** Native `<textarea>` keyboard behavior — no custom key handling.

**Screen reader:** `invalid` sets `aria-invalid="true"`; `disabled`/`readOnly` use their native
attributes (disabled removes from tab order, readOnly keeps it focusable). Label/helper-text
association is the caller's job unless composed via `FormField`.

**Focus:** Focus lands directly on the native `<textarea>` element (no wrapper span, unlike
Input).
