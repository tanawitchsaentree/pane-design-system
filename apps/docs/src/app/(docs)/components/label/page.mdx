# Label

Label is the `<label>` wrapper for any form control — text, checkbox, radio, textarea, select. It
renders its copy through `Text` (no bespoke font styling) and can add a required indicator. Use it
standalone when wiring a control by hand with `htmlFor`, or let `FormField` wire it automatically
when composing a full field.

```tsx
import { Label } from 'dial-react';
```

## Variants

Label has one real state prop, `required`, which renders a visible `*` plus a visually-hidden
"(required)" cue so the requirement is announced to screen readers too, not just shown visually.

<Demo code={`<Label htmlFor="name" required>Full name</Label>
<input id="name" type="text" placeholder="Jane Doe" />`}>
  <RequiredLabel />
</Demo>

The native `htmlFor`/`id` association works the same way for any labelable control, not just a
plain `<input>` — here it's paired with `Textarea`.

<Demo code={`<Label htmlFor="bio">Bio</Label>
<Textarea id="bio" placeholder="Tell us about yourself" />`}>
  <LabelWithTextarea />
</Demo>

`asChild` renders Label's typography and semantics onto a single child element instead of a plain
`<label>` — useful when the label needs to wrap a whole composed row (e.g. a checkbox plus its
copy) rather than pairing with `htmlFor` from the outside.

<Demo code={`<Label asChild>
  <span>
    <input type="checkbox" defaultChecked />
    Send me product updates
  </span>
</Label>`}>
  <AsChildLabel />
</Demo>

## Keyboard interaction

No independent keyboard behavior — clicking/tapping the label moves focus to or activates its
associated control via native `<label for>` behavior.

## Accessibility

**Keyboard:** No independent keyboard behavior — clicking/tapping the label moves focus to or
activates its associated control via native `<label for>` behavior.

**Screen reader:** Native `<label for>` association exposes the control's accessible name. When
`required`, a visually-hidden "(required)" string is announced in addition to the visible `*`
(which is `aria-hidden`), satisfying the non-color/non-glyph-only cue rule.

**Focus:** Label itself is not focusable; it delegates focus to the associated control when
clicked.
