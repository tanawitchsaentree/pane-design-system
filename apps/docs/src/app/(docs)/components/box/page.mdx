# Box

Box is the base primitive of the whole system — a plain, styleable box-model reset rendered as a
`div` by default.

```tsx
import { Box } from 'dial-react';
```

## Usage

Box is the base primitive of the whole system (D-012) — a plain, styleable box-model reset
rendered as a `div` by default. It carries no variant or size prop; every other layout primitive
(Flex, Stack, Center, Grid, Container, and more) is built on top of it. Reach for Box directly
when you just need an unstyled wrapper element, an escape hatch for inline `style`/`className`, or
a polymorphic root via `asChild`.

## Variants

Box has no variant or size prop by design — it stays a plain box-model reset. The one behavioral
switch it offers is `asChild`, which changes what element it renders as rather than how it looks.

<Demo code={`<Box asChild style={{ display: 'inline-block', padding: 8, border: '1px solid var(--ds-color-border-hairline)' }}>
  <a href="#">Box rendered as an anchor via asChild</a>
</Box>`}>
  <BoxAsChildLink />
</Demo>

## Composition

Box has no card/panel variant of its own, but a bordered, padded, surface-colored Box is the most
common composition pattern for it — nesting plain Box elements for the title and body instead of
reaching for a heavier component when no card-specific behavior (hover, click, media slot) is
needed.

## Keyboard interaction

No keyboard behavior beyond native Tab focus — Box is a non-interactive layout primitive.

## Accessibility

**Keyboard:** N/A — non-interactive layout primitive.

**Screen reader:** No inherent role or label; announced according to whatever element it renders
(`div` by default, or the `asChild` child's own semantics). Verified axe-clean in tests.

**Focus:** Not focusable by default (no tabIndex added). If `asChild` is used with a naturally
focusable element (e.g. `<a href>`), that element's native focus behavior applies unchanged.
