# Switch

Switch renders a native `<input type="checkbox" role="switch">` visually hidden underneath a
custom track-and-thumb control. It reuses Checkbox's visually-hidden-input technique so it keeps
native Tab/Space keyboard behavior for free, but announces to assistive tech as a switch (on/off)
rather than a checkbox. Use it for immediate-effect binary settings (e.g. "Dark mode",
"Notifications") rather than choices that need explicit form submission.

```tsx
import { Switch } from 'dial-react';
```

## Accessibility

**Keyboard:** Tab to focus, Space to toggle — native `<input type="checkbox">` behavior underneath
`role="switch"`, verified in `Switch.test.tsx` (tab, then `Space` toggles `checked`).

**Screen reader:** The native input carries the real `checked`/`disabled` state and receives
focus; `role="switch"` makes assistive tech announce it as "on"/"off" rather than
"checked"/"unchecked". The custom track/thumb visual is `aria-hidden`.

**Focus:** Focus-visible renders as an outline ring around the track, not a shadow. The wrapper
(`label`) has a 40px hit area (`min-inline-size`/`min-block-size: size.control.sm`) while the
visible track (`size.avatar.lg` = 48px wide × `size.icon.lg` tall) stays visually distinct and
centered. The track was specifically sized so its 20px thumb (`size.icon.md`) has a real ~24px
travel distance between off and on — previously the track matched the thumb+offset almost
exactly, giving effectively 0px of visible movement.
