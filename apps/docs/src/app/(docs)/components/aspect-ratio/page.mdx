# AspectRatio

AspectRatio constrains its children to a fixed width/height ratio, extending Box.

```tsx
import { AspectRatio } from 'dial-react';
```

## Usage

AspectRatio constrains its children to a fixed width/height ratio, extending Box (D-012). Use it
for media placeholders (images, video embeds, thumbnails) where you need consistent proportions
regardless of content or container width — either via named presets bound to `ratio.*` tokens, or
an arbitrary numeric ratio as an escape hatch.

## Variants

Named presets — `square`, `video`, `photo`, `portrait`, `golden` — bound to `ratio.*` tokens, plus
a numeric escape hatch for ratios the token scale doesn't cover.

## Keyboard interaction

No keyboard behavior beyond native Tab focus — AspectRatio is a non-interactive layout primitive.

## Accessibility

**Keyboard:** N/A — non-interactive layout primitive.

**Screen reader:** No inherent role; ratio is exposed via `data-ratio` (presets) or inline style
(numeric) for styling only, not conveyed to assistive tech. Verified axe-clean in tests.

**Focus:** Not focusable itself; forwards ref to the underlying DOM node.
