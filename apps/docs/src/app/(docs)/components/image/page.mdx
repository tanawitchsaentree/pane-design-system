# Image

Wraps a native `<img>` for plain content images — article heroes, gallery tiles, any picture that
isn't expected to need a fallback-on-error state.

```tsx
import { Image } from 'dial-react';
```

## Demo

<Demo code={`<Image src="https://picsum.photos/seed/dial/320/180" alt="Decorative landscape placeholder" />`}>
  <BasicImage />
</Demo>

## Usage

Image wraps a native `<img>` for plain content images — article heroes, gallery tiles, any picture
that isn't expected to need a fallback-on-error state. It optionally composes Wave 1's
`AspectRatio` component to constrain the image to a fixed ratio instead of relying on intrinsic
dimensions, and supports optional corner rounding (D-008 soft-rounded scale). It ships no
client-side error/fallback state of its own — that concern belongs to Avatar.

## Variants

Image supports an optional fixed `ratio` (via the composed AspectRatio) and optional corner
`radius`; `fit` (`cover`/`contain`) controls `object-fit`.

  alt="Placeholder card artwork"

  radius="lg"
/>`}>

## Fit

`fit` maps to `object-fit`: `cover` (default) crops to fill the frame, `contain` shows the whole
image inside it, letterboxing if the aspect ratios don't match.

<Demo code={`<Image
  src="https://picsum.photos/seed/dial-fit-cover/320/180"
  alt="Landscape placeholder cropped to fill its frame"
  fit="cover"
/>

  alt="Landscape placeholder shown in full without cropping"

## Loading strategy

`loading` maps 1:1 to the native `<img>` attribute: `eager` for above-the-fold images that should
load immediately, `lazy` (the default) for below-the-fold images the browser can defer.

  src="https://picsum.photos/seed/dial-eager/160/120"

## Accessibility

**Keyboard:** N/A — Image is non-interactive and never receives focus.

**Screen reader:** `alt` is a required prop and always exposed on the underlying `<img>` as its
accessible name/description; there is no fallback path that could silently drop it.

**Focus:** Not focusable; no focus-visible styling is defined.
