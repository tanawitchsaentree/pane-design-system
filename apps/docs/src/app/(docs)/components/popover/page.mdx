# Popover

Popover is a lightweight, trigger-anchored floating panel for auxiliary content — menus, filter
panels, inline forms, or extra detail that doesn't need to block the page.

```tsx
import { Popover } from 'dial-react';
```

## Usage

Popover is a lightweight, trigger-anchored floating panel for auxiliary content — menus, filter
panels, inline forms, or extra detail that doesn't need to block the page. Unlike Dialog, it is
non-modal by default: focus stays on the trigger, and the panel dismisses on click-outside or
Escape without trapping focus or inerting the background. It renders through a portal at
`z-index: var(--ds-z-index-popover)` (1500) with `shadow.elevation.md`, positioned relative to its
trigger.

<DoDont

    "Use Popover.Anchor when the visual anchor point needs to differ from the element that actually opens the popover.",
    "Pair with Popover.Arrow when a visual pointer back to the trigger helps orient the user.",

  donts={[
    "Don't use Popover for content that must block user interaction with the rest of the page — that's Dialog's job.",

    "Don't hand-roll click-outside or Escape dismissal — both are wired by @radix-ui/react-popover, not custom code.",

## Variants

`modal` (on `Popover.Root`, default `false`) switches the popover into a focus-trapping mini-modal
layer for the rare case that needs it. `side` (on `Popover.Content`, default `'bottom'`) picks
which edge of the trigger the panel renders against.

<Demo code={`<Popover.Root modal>
  <Popover.Trigger asChild>
    <Button variant="outline">Modal popover</Button>
  </Popover.Trigger>
  <Popover.Content side="right">
    <p>This popover traps focus like a mini-modal.</p>
    <Popover.Close asChild>
      <Button variant="ghost" size="sm">Close</Button>
    </Popover.Close>
  </Popover.Content>
</Popover.Root>`}>
  <ModalPopover />
</Demo>

A popover can hold more than static text — here it wraps a small inline form (two `FormField`s
plus a save action), the "quick edit without leaving the page" pattern the component exists for.

<Demo code={`<Popover.Root>
  <Popover.Trigger asChild>
    <Button variant="outline">Add contact</Button>
  </Popover.Trigger>

## Accessibility

**Keyboard:** Escape closes the popover; focus is not trapped inside it by default (non-modal), so
Tab continues through the surrounding page unless `modal={true}` is set.

**Screen reader:** Radix renders the content with `role="dialog"`. Verified axe-clean when open in
`Popover.test.tsx`.

**Focus:** Focus remains on the trigger by default when the popover opens (non-modal); click-outside
and Escape both close it (confirmed in tests).
