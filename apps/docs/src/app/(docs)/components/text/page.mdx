# Text

The inline/span element for body copy — captions, labels, paragraph runs, and any place you need
styled text without owning a heading's document-outline semantics.

```tsx
import { Text } from 'dial-react';
```

## Usage

Text is the inline/span element for body copy — captions, labels, paragraph runs, and any place
you need styled text without owning a heading's document-outline semantics. It renders a plain
`span` by default and carries the type scale (size), weight, and semantic color role. Use `asChild`
when the surrounding context needs a different real tag (`p`, `label`, etc.) while keeping Text's
visual treatment.

## Variants

Text has no named "variant" prop, but `size`, `weight`, `color`, and `truncate` each drive a
distinct visual state.

## Accessibility

**Keyboard:** N/A — Text is non-interactive and never receives focus.

**Screen reader:** No implicit ARIA role is applied; content is read as plain text. `asChild` lets
callers swap in the correct semantic tag (e.g. `label`) for their context so assistive tech gets
accurate semantics.

**Focus:** Not focusable; no focus-visible styling is defined.
