# Fieldset

Fieldset is a native `<fieldset>` + `<legend>` wrapper for a related group of controls, most
commonly a Radio group. It renders its legend copy through `Text` rather than re-declaring
typography, and its `disabled` prop uses the native fieldset-disabled cascade to disable every
nested control at once.

```tsx
import { Fieldset } from 'dial-react';
```

## Variants

Fieldset has one real state prop, `disabled`, which cascades through the native `<fieldset
disabled>` attribute to every nested control at once — no per-child wiring needed.

<Demo code={`<Fieldset legend="Notification method (disabled)" disabled>

    <Radio name="notify-disabled" value="email" defaultChecked />
    Email
  </label>
  <label>
    <Radio name="notify-disabled" value="sms" />
    SMS
  </label>
</Fieldset>`}>

Fieldset also groups controls other than Radio — here a set of `Checkbox` inputs sharing one
legend, since a multi-select "pick any of these" question needs the same accessible group name a
radio group does.

## Keyboard interaction

No independent keyboard behavior of its own; when `disabled`, every nested native form control is
removed from the tab order automatically via the native fieldset cascade.

## Accessibility

**Keyboard:** No independent keyboard behavior of its own; when `disabled`, every nested native
form control is removed from the tab order automatically via the native fieldset cascade.

**Screen reader:** `<legend>` is the group's accessible name — assistive tech announces it before
each control's own label, exposing the fieldset as `role="group"` with that name (verified in
`Fieldset.test.tsx` via `getByRole('group', { name: ... })`). The native `disabled` attribute
communicates the disabled state for all nested controls with no extra prop-drilling.

**Focus:** Not focusable itself; focus moves to/among its nested controls as usual, respecting the
disabled cascade.

## Related

- `Radio` — the most common control grouped inside Fieldset, since a radio group's shared `name`
  needs a legend for its accessible group name.
- `Checkbox` — can also be grouped inside Fieldset when several checkboxes represent one logical
  question.
- `Text` — Fieldset's legend renders through `Text` for consistent typography.
