# Link

Wraps a native `<a>` for navigation — inline body-copy links, nav items, or any anchor to another
page/section.

```tsx
import { Link } from 'dial-react';
```

## Demo

  <BasicLink />
</Demo>

## Usage

Link wraps a native `<a>` for navigation — inline body-copy links, nav items, or any anchor to
another page/section. It defaults to a quiet, non-underlined style at rest (D-001: calm, underline
appears on hover/focus) and automatically adds `target="_blank" rel="noopener noreferrer"` to
absolute cross-origin `href`s so callers don't have to remember the security attributes.

## Variants

Link supports two treatments via `variant`: `subtle` (default, plain text color) and `default`
(spends the scarce brand accent).

## Composition

Link's most common home is inline, inside a sentence of body copy rather than sitting alone —
this shows two `Link`s composed inside `Text`, styled with the quiet `variant="subtle"` default.

<Demo code={`<Text>

  <LinkInSentence />

An absolute cross-origin `href` is automatically treated as external: `Link` adds
`target="_blank" rel="noopener noreferrer"` on its own, so callers don't have to remember the
security attributes for outbound links.

## Accessibility

**Keyboard:** Native `<a>` semantics — `Tab`/`Shift+Tab` to move focus, `Enter` to activate.

**Screen reader:** Renders a real `<a href>` with its own text content as the accessible name;
`target`/`rel` are set correctly for cross-origin links so assistive tech and browsers handle the
new-tab behavior predictably.

**Focus:** `:focus-visible` always shows the dedicated focus-ring token (color/width/offset) —
underline is a style choice that only appears on hover/focus, but focus visibility itself is never
negotiable per the component's own doc comment.
