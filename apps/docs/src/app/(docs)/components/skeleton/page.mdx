# Skeleton

A loading placeholder shape — a shimmering block that stands in for content (text lines, avatars,
images) while real data loads.

```tsx
import { Skeleton } from 'dial-react';
```

## Usage

Skeleton is a loading placeholder shape — a shimmering block that stands in for content (text
lines, avatars, images) while real data loads. It's a pure CSS shimmer animation with no client
state, so it's safe to render on the server. Use `width`/`height` as a layout escape hatch to
match the real content's arbitrary dimensions.

## Variants

Skeleton supports three shapes via `variant`: `text` (default), `circle`, and `rect`, composable
together to placeholder a whole row.

## Composition

A common real use is placeholdering a whole `Card` while its content loads: a `rect` skeleton
standing in for the media, `text` skeletons standing in for the title and body lines.

<Demo code={`<Card.Root style={{ maxWidth: 320 }}>
  <Card.Media ratio="video">
    <Skeleton variant="rect" width="100%" height="100%" />
  </Card.Media>
  <Card.Body>
    <Stack gap="200">
      <Skeleton variant="text" width="70%" />
      <Skeleton variant="text" width="100%" />
      <Skeleton variant="text" width="90%" />
    </Stack>
  </Card.Body>
</Card.Root>`}>
  <SkeletonCardLoading />
</Demo>

The same `circle` + `text` pairing also placeholders a list of rows (e.g. an avatar plus a
two-line summary) before real data arrives.

## Accessibility

**Keyboard:** N/A — Skeleton is non-interactive and never receives focus.

**Screen reader:** Always `aria-hidden="true"` — a skeleton has no content of its own to announce.
The loading state itself should be announced by a nearby Spinner/status region if one exists.

**Focus:** Not focusable; no focus-visible styling is defined. `prefers-reduced-motion` swaps the
shimmer sweep for a static low-contrast fill instead of disabling the placeholder entirely.
