# Grid

Grid is the CSS Grid layout primitive extending Box, defaulting to a 12-column grid.

```tsx
import { Grid } from 'dial-react';
```

## Usage

Grid is the CSS Grid layout primitive extending Box (D-012), defaulting to a 12-column grid per
D-007. Use it for two-dimensional layouts — column-based page sections, card grids, or any
arrangement that needs explicit column counts and responsive breakpoint overrides
(`sm`/`md`/`lg`/`xl`).

## Keyboard interaction

No keyboard behavior beyond native Tab focus — Grid is a non-interactive layout primitive.

## Accessibility

**Keyboard:** N/A — non-interactive layout primitive.

**Screen reader:** No inherent role; grid column counts are exposed via inline CSS custom
properties (`--ds-grid-cols`, `--ds-grid-cols-sm/md/lg/xl`) and `gap` via a `data-gap`
attribute — none of this is conveyed to assistive tech. Verified axe-clean in tests.

**Focus:** Not focusable itself; forwards ref to the underlying DOM node.
