## Install

```bash
npm install dial-react dial-tokens react react-dom
```

`dial-tokens` is **required**, not optional — every component's stylesheet references `var(--ds-*)`
custom properties that only `dial-tokens`'s own CSS defines. Installing `dial-react` alone gives
you unstyled markup with no error to tell you why.

## Setup

Import both stylesheets once, near your app's root (order doesn't matter — they don't overlap):

```tsx
import 'dial-tokens/css';
import 'dial-react/styles.css';
```

For dark mode, also import `dial-tokens/css/dark` and set
`document.documentElement.setAttribute('data-theme', 'dark')` — see [Dark mode](/dark-mode) for
the full theme-switching details.

## Usage

```tsx
import { FormField, Input, Button, Stack } from 'dial-react';

function SignInForm() {
  return (
    <Stack gap="400">
      <FormField label="Email" required>
        <Input type="email" placeholder="jane@example.com" />
      </FormField>
      <Button intent="primary">Sign in</Button>
    </Stack>
  );
}
```

Every form control follows the same controlled/uncontrolled duality as its native HTML
counterpart (`value`/`onChange` or `defaultValue`), and every component that manages a collection
of items (`Listbox`) speaks a consistent `selectedKeys`/`onSelectionChange` vocabulary instead of
leaking whichever behavior engine sits underneath it.
