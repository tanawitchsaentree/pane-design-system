# Introduction

Dial is a Braun-derived design system — calm, restrained, and accent-scarce. Its lineage is a
single style direction locked at the very start of this system's build: warm-neutral surfaces, no
decorative drop-shadows, a flat type scale where hierarchy comes from position and weight rather
than font size, and one scarce accent color reserved for the single most important interactive
element in a given view (never used to decorate or emphasize plain text).

Dial ships as two npm packages — `dial-tokens` (the token pipeline: primitive → semantic →
component, three themes) and `dial-react` (presentational React components styled entirely
through those tokens' CSS variables, with behavior for anything with real keyboard/focus
complexity borrowed from Radix UI or React Aria rather than hand-rolled).

Start with [Installation](/installation) to set up both packages, or jump straight to
[Foundations](/foundations/colors) to see the token scales themselves, or browse
[Components](/components/button) to see every shipped component with a live, interactive demo.
