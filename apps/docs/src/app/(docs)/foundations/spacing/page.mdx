variable — this is the same scale `Box`/`Flex`/`Stack`/`Grid`'s `gap`/`padding` props draw from.
`size.control.*` below is separately the minimum interactive hit-area floor (sm = 40px, the
web-first minimum), not a spacing value.

## The laws behind the scale

A scale on its own doesn't say how much space belongs between two particular things — that's
what these seven laws govern. They're invariant across every system kiln builds (the numbers
below are Dial's own; the laws themselves never change per-system). Each is measured, not
inferred from CSS source — `tooling/spacing-check.mjs` runs every one against a real rendered
page via `getComputedStyle`/`getBoundingClientRect`, because CSS that looks correct can still
measure wrong (this system's own landing page once shipped a divider with a real border and a
real padding rule that still measured 0px clearance — the defect that motivated this page).

| Law | Statement | Gate |
|---|---|---|
| L1 — Scale purity | Every gap, padding, and margin resolves to a real scale step. An off-grid value is a bug, not a stylistic choice, except the named optical cases in L7. | G-S2 |
| L2 — Monotonic proximity | Moving up nesting levels, spacing must never decrease. The gap *between* two things exceeds the gap *within* either of them. | G-S3 |
| L3 — Clearance | Content next to any visible boundary keeps at least the clearance token of distance from it, on the facing side. | G-S1 |
| L4 — Bound pairs tightest | The smallest, most tightly coupled pair on a page (icon↔label, bullet↔text) gets the smallest gap in its surrounding context. | — |
| L5 — Heading binding | A heading's space-above exceeds its space-below, always. | G-S4 |
| L6 — Rhythm | Structurally-equivalent repeated units share identical gaps. | G-S5 |
| L7 — Optical honesty | A ≤2px deviation is allowed only when it names why, via a real `data-optical="reason"` annotation. | G-S2 |

## Why loose density

Dial's relationship ladder (below) runs in **loose** mode, not tight or medium — not a default
guess, but a direct consequence of two decisions already locked before this page existed. D-001
calls the Braun reference's mood "spacious/comfortable": a hardware front panel with few large
controls, not a dense dashboard. D-003 picked an 8px base unit over a 4px one for the same reason
— base-4 suits dense UI/dashboards, which is explicitly not what this system is for.

## Relationship ladder

Each row is a real pairing that exists somewhere in Dial's own shipped components — not invented
numbers, and not `spacing-control`'s own reference figures either (that skill's base-4 numbers
would themselves violate L1 if copied directly onto Dial's base-8 scale).

| Relationship (tightest → loosest) | Token | Value | Real precedent |
|---|---|---|---|
| Bound pair (icon↔label) | `space.inline.sm` | 8px | `Button.module.css` |
| Compound-control stack (label→control→helper text) | `space.stack.sm` | 8px | `FormField.module.css` |
| Fields/rows within one group | `space.stack.md` | 32px | Majority real usage across form layouts |
| Component inner padding | `space.inset.md` | 24px | `Card.module.css` |
| Component ↔ component | `space.inline.lg` / `space.stack.lg` | 24px | Two Cards side by side |
| Sub-group ↔ sub-group | `space.600` (no semantic alias yet) | 48px | Two option groups within one form |
| Heading space-above / space-below | `space.stack.lg` / `space.stack.sm` | 32px / 8px | Above always exceeds below (L5) |
| Section ↔ section | `space.700` (no semantic alias yet) | 64px | Two major page sections |
| Clearance token (L3) | `space.inline.lg` (inline) / `space.inset.lg` (block) | 24px / 32px | Content vs. any divider or rule |

Two relationship classes — sub-group↔sub-group and section↔section — don't have a semantic alias
yet; component and docs code that needs them today references the primitive step directly. That's
a real gap in the token architecture, logged rather than papered over with an invented name.

This derivation is locked as **D-027** in `system/DECISIONS.md`. The full worked derivation,
including every grep'd precedent, lives in `.claude/skills/spacing-engine/references/dial-parameters.md`.
