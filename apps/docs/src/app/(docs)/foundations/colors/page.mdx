# Colors

A warm-neutral ramp from a cream base, with a single scarce accent (brand) reserved for the one
thing a user should act on. Every swatch below reads its real hex value from the built token CSS
(`packages/tokens/build/css/light.css`) at build time — nothing here is a hand-typed hex.

## Primitives

The raw neutral, brand, and semantic-role (success/warning/danger/info) ramps every alias below
draws from. Components never reference a primitive step directly — only the Semantic tier below.
