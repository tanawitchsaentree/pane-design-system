# Motion

Default blueprint motion — no evidence in any reference image justified bending timing/easing
from the standard scale, so this system keeps it as-is. `transition-*` shorthands compose a
`duration.*` with a `cubic-bezier.*` easing curve; components pick the shorthand that matches
their situation (enter/exit vs. a plain hover/press state change) rather than assembling
duration+easing by hand each time. Click Toggle on any row below to feel the real timing.
