# Icons

<div className="docs-placeholder">
  Dial does not ship a formal icon set as of this build. `Icon` (see the{' '}
  <a href="/components/icon">Icon component page</a>) only sizes and colors whatever SVG a
  consumer passes as its child — it has no bundled icon library dependency and no fixed
  inventory to list here. This gap is logged in `BACKLOG.md` under "Icons foundation page —
  source of truth unclear."
</div>

## What does exist

Two real, build-verified pieces of the icon system:

### Size scale

`size.icon.*` — the t-shirt scale every icon slot in the system (Button's `leftIcon`/`rightIcon`,
IconButton's child, Icon's own `size` prop) resolves against.

<div style={{ display: 'flex', gap: 'var(--ds-space-inline-lg)', alignItems: 'flex-end', flexWrap: 'wrap' }}>
  <IconSizeSwatch size="sm" />
  <IconSizeSwatch size="md" />
  <IconSizeSwatch size="lg" />
  <IconSizeSwatch size="xl" />
</div>

### Color roles

`icon-color` plus the same semantic text-color roles Icon's own `color` prop accepts
(`currentColor`/`default`/`subtle`/`disabled`/`inverse`) — see the
[Icon component page](/components/icon) for the full prop table.
