# Pane

Pane is interface that floats in the reader's own space. A profile, a feed or a player sits on panes of clear glass over a real scene (a room, a forest, a street), the way visionOS windows float in a room. It is for personal and media apps on the web where the picture behind is part of the experience. It must never become grey frosted plastic, decoration that costs legibility, a look that only works on one wallpaper, or glass where people simply need to read.

Generated by kiln (`tooling/kiln/design-md.mjs`) from the tokens, the concept, every component's reasons and the decision log. Edit those, never this file.

## How to use this system

Install `pane-react` and `pane-tokens`, import `pane-react/all.css` once, and build from the components below before writing new ones. Use semantic tokens (`var(--ds-…)`) and never a raw colour, size or duration. Other platforms read the same names: `pane-tokens/tailwind`, `/swift`, `/kotlin`, `/dart` and `/figma`.

This file cannot check your work, so keep to what kiln would have measured:

- body text at 4.5:1 or more in every theme, over every backdrop the screen can show
- one loud element per surface, and no colour that carries meaning alone
- every control reachable and visible by keyboard, with its focus ring
- spacing, corners and motion only from the tokens, and nested corners that follow the outer one

## Principles

- **P1 The scene is part of the interface.** What is behind a pane belongs to the experience, so glass shows it instead of covering it.
- **P2 Measured, not predicted.** Contrast over a photograph depends on the photograph, so every value that decides legibility comes from measuring real pixels.
- **P3 Panes are objects in space.** A pane is a physical sheet with an edge, a weight and a place in a stack.
- **P4 Things settle.** Objects have weight, so they arrive, respond and come to rest instead of snapping.
- **P5 One loud thing per pane.** A reader should never have to choose between two equal calls to action.
- **P6 Reachable by anyone.** Glass is a mood, never the carrier of meaning, so everything works without it and without sight of it.
- **P7 Reading surfaces stay ordinary.** Where people read or configure (documentation, settings, forms), the scene would only compete with the words.
